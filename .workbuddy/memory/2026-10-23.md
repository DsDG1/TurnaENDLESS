**关键决策与坑**
- `resolveProp` 里别名必须排在「按 tag 挑 emoji」之前：`hat` 既是标签（top_hat / cap 都挂着）又是别名，按标签排序会挑到 `cap` —— 程序在猜。
- autofix 别名替换会把说话者改成 `delivery_mouse`，若模型没把该角色写进 cast 就变成 `E-ENTITY-UNKNOWN`：替换命中时把目标角色补进 `batch.cast`。
- `git bash + python -` 的 heredoc 会把正则里的 `\s` 篡改成 `/s`（MSYS 路径转换）：带反斜杠的正则要么写成字符类，要么改用行处理。
- 派生卡插在 scenes 最前面让 `E-PRIMED` 天然成立；卡数统计要 `filter(s => s.type !== 'derive')` 再 `+ ast.derived.length`，否则 K5 虚高。
- `lab render --pair` 的 run 参数支持 `smoke` 短名（`repoPath` 会拼到仓库根）。
